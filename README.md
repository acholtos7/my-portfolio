# Achol Tos — Portfolio

A responsive personal portfolio starter for a software engineer with an AI technology focus. Built with HTML, CSS, and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.

## Personalize before sharing
- Replace the placeholder email address in `index.html`.
- Update skills to reflect technologies you have actually used.
- Replace illustrative project concepts with real projects, links, screenshots, and outcomes.
- Add your real work experience and education.
- Add GitHub and LinkedIn links when ready.

## GitHub Pages
In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub Pages will publish after its deployment workflow completes.
